## What this solves

Same topic, same learning objective — but the pupils in a class have different abilities and needs. Some can compare and reason directly, some need sentence frames and a word bank, and some need pictures and a hands-on sorting task to stay engaged. Teachers often end up re-making three worksheets by hand.

This resource turns the "same" worksheet into three ready versions — **standard, scaffolded and visual** — with teacher notes explaining **what changed in each version and why**, plus a comparison table. Teachers can print them as they are, or use them as a template for their own class versions.

The topic is change in a fictional neighbourhood, suitable for P4-P6 Humanities (the "society" strand of General Studies).

## Learning objectives

All three versions aim at the same learning objective; only the level of support differs. By the end, pupils can:

1. Find the differences between a community "then" and "now", from text or pictures.
2. Sort community features into three groups: "then", "now" and "both then and now".
3. State one change in the community and give a possible reason for it.
4. Name one community feature worth keeping and give a simple reason.

## Teaching steps

1. **Introduction (5 min)** — Project two contrasting pictures (one old, one new; sketches are fine) and ask: "What is different about this community?" Let pupils answer freely, without judging.
2. **Handing out versions (2 min)** — Give out the standard, scaffolded or visual version according to need. All three can run in the same classroom at once.
3. **Independent work (18 min)** — Pupils complete their worksheet. The scaffolded version provides sentence frames; the visual version is mostly cut-and-paste sorting. Circulate and support individuals.
4. **Pair sharing (5 min)** — Mix pupils who had different versions and have them tell each other one change they found.
5. **Whole-class wrap-up (5 min)** — Write "change + reason" on the board and sum up: changes in a community are often linked to population, transport and people's needs.

## Answer key and marking notes

- **Sorting table (common to all three versions)** — Then: wooden huts, market stalls, communal standpipe, ferry, the open ground by the temple; Now: high-rise blocks, piped water, supermarket, MTR station, park / playground; Both then and now: market, Tin Hau temple. Pupils work from the vocabulary given and are on track if they name most of these.
- **Reason for the change (scaffolded version, multiple choice)** — Correct answer A (more people, so faster transport was needed). The standard and visual versions ask this as an open question.
- **Open writing** — A good answer contains "one change + one reason", for example "People used to take the ferry, but now there is an MTR station, because the population grew and faster transport was needed." Naming the change earns 1 mark; adding a plausible reason earns 1 more.
- **What is worth keeping** — A good answer contains "one feature + one reason", for example "Keep the Tin Hau temple, because it is part of the community's history and the elders have memories of it."
