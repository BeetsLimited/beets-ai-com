> 一筆撥款只花一次，工具卻會一直用下去。這份工作表只做兩件事：**把錢從哪裡來寫清楚，把錢往哪裡去算出來。**

## 這個資源解決什麼問題

教育局通函第 156/2026 號（附錄一第 2 節「善用相關資源」）說明：政府在 **2025/26 至 2027/28 學年**內提供一筆過 **50 萬元**撥款，即「**『智』啟學教**」，用於購置、訂閱或租用相關服務，以及資助學生參加活動；同節亦提及 eLAFP 訂閱券與資訊科技綜合津貼。學校因此同時要管三個錢包，而三個錢包的用途、年期與紀錄要求並不相同。

於是同一個問題每年出現三次：這一筆錢，應該從哪個錢包出？多數學校卡在三處：

- **三個錢包混在一起算。** 一張總表列出「AI 相關支出」，年尾卻答不出某項支出動用了哪一筆、還剩多少、有沒有越過該筆撥款的用途。
- **只比較第一年。** 訂閱制、自建、混合三種做法的支出曲線完全不同：一種是每年一筆，一種是開頭一大筆、之後是維護，一種是兩者相加。只看第一年，等於沒有比較。
- **沒有逐項問合約條款。** 通知期與自動續約、加價上限、退出時資料帶走的格式——這三項不會寫在報價單的價目欄上，卻決定三年後學校能不能體面地走。

本工作表只處理**錢與合約**：哪一個錢包、哪一種成本情境、每學生每年多少、簽約前問哪三題、幾時要向誰交代。工具的教學適用性屬另一份評選表的工作；裝置、網絡、帳號、過濾與儲存屬另一份基建檢查表的工作。

**全份不出現任何價格、折扣或建議金額。** 所有金額欄一律留空，由學校按實際報價填寫；工作簿內亦不出現任何具名商業工具或供應商，一律以代號表示，由學校自行對應。

## 規劃目標

完成本工作簿後，學校能夠：

1. 把「『智』啟學教」一筆過撥款、資訊科技綜合津貼與其他來源**分開**記錄，逐項寫出用途、年期、已承擔金額與負責同事。
2. 用**同一組欄位**把訂閱制、自建、混合三種成本情境並排填寫，令三者可以互相比較，而不是各寫各的。
3. 用**一條公式**算出每個情境的每學生每年成本，並在同一批學生人數之下比較。
4. 在簽約之前，把通知期與自動續約、加價上限、退出時資料帶走格式三題問到書面答案。
5. 把中期報告、總結報告、法團校董會／學校管理委員會批核、上載學校網頁四項程序寫進一張時間表。

本工作表以育人為本、素養為先、應用導向、智能向善為價值取向，並環繞人工智能素養的三條學習範疇（人工智能的基本運作原理、人機溝通和協作、應用人工智能的反思）而設計：錢決定學校買得到甚麼，但買得到甚麼不等於學生學得到甚麼。因此工作簿內每一次支出都要對應一句「這一筆支持哪一條學習範疇、哪一科的學與教」，並寫明由誰專業把關、學習數據存放在哪裡。

## 規劃步驟

工作簿共七頁：說明、撥款與來源、三個情境頁（訂閱制、自建、混合）、三情境並排比較、問責時間表。建議順序如下。

### 第一步：先把三個錢包分開

在「撥款與來源」頁，一行一個錢包，欄位固定：

| 錢包 | 用途（按通函或學校現行安排填寫） | 適用年期 | 已分配金額 | 已承擔金額 | 餘額 | 負責同事 |
|---|---|---|---|---|---|---|
| 「『智』啟學教」一筆過撥款 | 購置、訂閱或租用相關服務；資助學生參加活動（2025/26 至 2027/28 學年內） | 2025/26 至 2027/28 學年 | | | | |
| 資訊科技綜合津貼 | 按學校現行安排填寫 | 按學年 | | | | |
| 其他來源 | 辦學團體、家長教師會、校外計劃、校本撥款等，逐項列明 | 按各自條款 | | | | |

撥款名稱須**逐字**照通函寫：「『智』啟學教」。名稱寫錯，日後在報告裡對不上，是常見的退回原因。

三個錢包分開之後，第二步才有意義：同一個成本情境可能同時動用兩個錢包，欄位分開，才知道哪一筆用得快。

### 第二步：三個成本情境，同一組欄位

三個情境頁的欄位完全相同，只有數字不同——這正是「並排」的意思：

| 項目 | 第一年 | 第二年 | 第三年 | 三年合計 | 說明 |
|---|---|---|---|---|---|
| 訂閱或授權費 | | | | | |
| 一次性設置（安裝、設定、資料遷移） | | | | | |
| 裝置（購置或折舊） | | | | | |
| 網絡與頻寬 | | | | | |
| 儲存空間 | | | | | |
| 維護與更新 | | | | | |
| 技術支援 | | | | | |
| 教師培訓 | | | | | |
| 教材與示例開發 | | | | | |
| 其他（自行填寫） | | | | | |

三個情境的分別在於錢的形狀，不在於價錢高低：

- **情境一 訂閱制**：每年一筆，支出平穩，開頭投入小；退出以合約為界，資料能否帶走全靠條款。
- **情境二 自建**：開頭一次性投入較多（裝置、設置、培訓），其後以維護與更新為主；東西在校內，但維護責任也在校內。
- **情境三 混合**：核心部分自建，其餘訂閱；兩條支出線同時存在，最容易被漏算的是「兩邊都要人跟」。

> 三個情境只是同一組數字的三種排列方式，**教育局並沒有要求學校採用其中任何一個**。學校按校情選擇，並在文件內寫明理由；工作簿只負責把三條路徑的錢算出來，不負責替學校決定。

### 第三步：每學生每年成本，一條公式

工作簿內只有一條公式，三個情境頁共用，並在三情境並排頁重複一次：

**每學生每年成本 ＝ 三年總支出 ÷ 3 ÷ 學生人數**

用法上有四點：

1. **分子用三年總支出，不是第一年支出。** 用第一年，自建一定看起來最便宜。
2. **分母用同一批學生人數。** 三個情境必須填同一個數字，否則比較不成立；人數用哪一個學年，寫在同一頁的「學生人數基準」一欄。
3. **公式只回答「每人每年多少」。** 它不回答「值不值得」——值不值得要回到評選表與學習範疇的對應。
4. **公式不計算「三年後」。** 三年之後的續期、加價與退出，寫在第四步的三題裡，不寫進公式。

### 第四步：簽約前必問三題

三題都要問到書面答覆，並把答覆的原文抄進「合約摘要」欄，而不是寫「已口頭確認」：

| 問題 | 要問到甚麼 | 為甚麼要問 |
|---|---|---|
| **通知期與自動續約** | 最短合約期、終止通知期（多少天或多少個月）、是否自動續約、續約前有否書面提醒 | 自動續約加一個長通知期，等於把三年變成六年 |
| **加價上限** | 續期可加多少、以甚麼為基準、有沒有上限、加價前多久通知 | 第二、三年的數字不是報價，是估算；沒有上限的估算不是估算 |
| **退出時資料帶走格式** | 學生的作品、教師的課件、提示與使用紀錄可否整批匯出、格式是甚麼、要不要另外收費、時限多長 | 帶不走的資料，等於把學校綁在一個地方 |

第三題最常被當成技術問題留給資訊科技同事，但它其實是採購問題：合約上沒有寫，日後就沒有立場要求。

### 第五步：問責時間表（空白）

通函所述的問責程序有四項，工作簿附一張空白時間表，四項都不得省略：

1. **中期報告**
2. **總結報告**
3. **提交法團校董會／學校管理委員會批核**
4. **上載學校網頁**

第 1、2 項按通函所述載於該學年的學校報告。時間表只有欄位——程序、負責同事、完成日期、備註——日期一律留空，由學校按校曆填寫；工作簿不預填任何日期。

這四項是通函所述的問責程序，**不是校本安排**：不能改寫為「按校本安排處理」，也不能因為學校慣常做法不同而略去其中一項。

填寫與覆檢建議由**校本數字教育專責小組**召集，並在學校發展計劃及／或學校周年計劃的層面檢視（教育局通函第 107/2026 號第 4 段），令預算、學與教與問責三份文件對得上同一個目標。

## 檢核要點

填好之後，逐項核對：

- □ 三個錢包分行填寫，每一項支出都寫明動用哪一個錢包。
- □ 撥款名稱逐字為「『智』啟學教」；50 萬元與 2025/26 至 2027/28 學年與學校收到的通函一致。
- □ 三個情境頁的欄位完全相同，可以逐行對照。
- □ 三個情境只有一條公式，且三頁的公式寫法一致。
- □ 三個情境使用同一個學生人數，並已寫明基準學年。
- □ 全份沒有預填任何金額、折扣或建議金額；所有金額欄由學校按報價填寫。
- □ 全份沒有出現具名商業工具或供應商。
- □ 通知期與自動續約、加價上限、退出時資料帶走格式三題，都有書面答覆並抄進合約摘要。
- □ 問責四項（中期報告、總結報告、法團校董會／學校管理委員會批核、上載學校網頁）齊全，沒有一項被改寫為校本安排。
- □ 時間表沒有預填日期，四項都留待學校填寫。
- □ 每一項支出都對應一句：支持哪一條學習範疇、哪一科的學與教、由誰專業把關。
- □ 已寫明下一次覆檢的月份與負責同事。

## 官方文件參考

本資源庫所有資源均按《中小學人工智能素養學習架構》編寫，並屬《中小學數字教育發展藍圖》的政策範圍。

本資源對應：

- **《中小學數字教育發展藍圖》**（三摺頁，p.2）：執行摘要的總體目標 3 與推行策略 8 要求學校在發展計劃中訂明數碼與 AI 教育的策略、資源與實施時間表；本工作表的「撥款與來源」與「問責時間表」兩頁，就是把「資源」與「時間表」寫成可核對的欄位。
- **附篇一：《中小學人工智能素養學習架構》**（p.1-4）：訂出三條學習範疇與四個學習階段的進程；工作簿內每一項支出都要對應其中至少一條學習範疇，否則該項支出不應計入 AI 預算。
- **附篇二：《中小學應用人工智能教學指南》**（pp.2-2 至 2-5）：就學校使用 AI 工具提出要求，包括以教學需要為先、處理學習數據，以及教師在課堂上的專業把關；「自建」與「混合」兩個情境的支援與培訓兩行，據此訂定。
- **教育局通函第 156/2026 號**（附錄一第 2 節「善用相關資源」）：一筆過 50 萬元撥款「『智』啟學教」，於 2025/26 至 2027/28 學年內購置、訂閱或租用、資助學生參加活動，並述及 eLAFP 訂閱券與資訊科技綜合津貼；同節訂明中期報告與總結報告載於該學年學校報告、提交法團校董會／學校管理委員會批核、上載學校網頁，並須成立校本數字教育專責小組。
- **教育局通函第 107/2026 號**（第 4 段）：把數字教育納入學校發展計劃及／或學校周年計劃。
