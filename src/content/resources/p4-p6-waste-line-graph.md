> 一條折線圖可以很清楚，也可以很誤導。這份工作紙要學生自己畫一條，然後互評：這一條線，有沒有說出數據真正說的事？

## 這個資源解決什麼問題

第二學習階段數學科要求學生製作折線圖，並從圖中讀出趨勢。這件事看起來很容易交給工具代辦：把數字輸入，圖就出來了。代價是學生不再需要做那幾個真正困難的判斷——軸的刻度是否等距、點應該放在哪裏、數字要不要湊整、單位寫在哪裏、圖中的線到底容許你說什麼。

本工作紙把這些判斷還給學生，而且固定兩頁：第一頁取數據、湊整、畫圖；第二頁是核實表（不超過五行）、趨勢描述與互評。頁數固定，是為了讓它成為一份完整的課堂工作紙，而不是被壓成一頁的摘要。

**本資源不提供任何廢物數字。** 數據由學生按教師指明的官方來源自行取得，並在核實表寫下來源與年份。頁內出現的數字示例，均屬虛構，只用來說明格式，不是資料來源，也不可以用來作答。

**課題來源**：以「廢物」作為練習折線圖的切入點，是本資源自訂的課題；官方示例採用的是其他課題。本頁沒有把廢物寫成官方示例的課題，教師可按校情改用其他題材，工作紙的結構不變。

## 學習目標

完成本工作紙後，學生能夠：

1. 從教師指明的官方來源，取得四個或五個年度的同一個數字，並記下來源與年份。
2. 依指定的單位把數據湊整，並寫出湊整的方式。
3. 在方格紙上製作一條折線圖：標題、兩軸名稱與單位、等距的刻度、每一點標明數值。
4. 用兩至三句描述圖中顯示的趨勢，只寫圖中看得見的，不作推測。
5. 依互評準則評一份同學的作品，指出一處做得好的地方與一處要改的地方。

## 使用步驟

一節六十分鐘，分四段，工作紙兩頁。

**第一段：取數據（15 分鐘）**

教師先指明一個官方來源（例如政府統計或部門年報），說明要取的是同一個數字、同一個單位、連續四個或五個年度。學生自行查出數字，把年份、原文數值、來源名稱與年份寫進第一頁的核實表。

核實表不超過五行（一行標題，四行數據）。最後一年留空，由學生自己填，避免全班抄同一個數而不去查。

| 年份 | 原文數值（連單位） | 來源名稱與年份 | 湊整後 |
|---|---|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

**第二段：湊整（10 分鐘）**

教師指定湊整的位數（例如湊整至百位或千位），學生把原文數值湊整，寫在最後一欄，並在旁註明湊整的方式。

示例（**虛構，不是資料來源**）：原文 12 345 噸，湊整至千位是 12 000 噸。這一行只示範格式，不可以抄進核實表。

湊整之後，全表只用湊整後的值畫圖；同一條線上的點，必須用同一個位數。

**第三段：畫圖（20 分鐘）**

在方格紙上完成五件事：

1. 寫標題：說明這是什麼數字、哪一個地方或範圍、哪一段時間。
2. 橫軸寫年份，縱軸寫數值，兩軸都寫單位。
3. 縱軸刻度等距，並在軸上標明數值。
4. 每一年只放一點，逐點標明數值。
5. 用直線把相鄰的點連起來（折線圖），不要把點連成一條平滑曲線。

**第四段：描述與互評（15 分鐘）**

先由學生自己寫兩至三句：這條線由哪一年到哪一年上升或下降、哪一段最陡、有沒有哪一年與前後不同。只寫圖中看得見的，不寫原因。

然後兩人一組互評，依第二頁的準則逐項打勾，並口頭說出一處做得好的地方與一處要改的地方。最後由教師抽兩份作品在投影上對照，重點看刻度與單位。

使用時間以每節六十分鐘為基礎，建議一節內完成，不多於四段。

## 答案與評分要點

**一條合格的折線圖，要同時符合以下五項**

| 項目 | 達標的樣子 |
|---|---|
| 標題 | 說得出是什麼數字、哪個範圍、哪段時間，而不是「我的圖」 |
| 兩軸 | 橫軸年份、縱軸數值，兩軸都有名稱與單位 |
| 刻度 | 縱軸刻度等距，軸上標明數值；不由零開始時，在圖上說明 |
| 點與線 | 每一年一點、逐點標值，相鄰的點以直線相連 |
| 數據一致 | 圖上的數值與核實表湊整後的值完全相同 |

**常見錯誤**

- **刻度不等距。** 縱軸每隔一格代表不同的數量，線的斜度就不再代表變化。
- **只改一半。** 核實表用了湊整後的值，圖上卻用原文數值，兩者不一致。
- **把年份當作連續數。** 中間缺了一年卻照樣連線，讀者會以為那一年有數據。
- **描述寫成推測。** 「因為多了外賣」屬原因，不屬圖中可見的趨勢；本頁只評後者。
- **標題與單位留空。** 沒有單位的一條線，可以被讀成任何東西。

**互評準則（學生用，逐項打勾）**

| 準則 | 有做到 | 要改 |
|---|---|---|
| 標題說明數字、範圍與時間 |  |  |
| 兩軸有名稱與單位 |  |  |
| 縱軸刻度等距 |  |  |
| 每點標明數值，並用直線相連 |  |  |
| 趨勢描述只寫圖中可見的 |  |  |

**評分以過程為本**：核實表有來源與年份、湊整方式寫得出來、圖與表一致，三項齊備即達標。本頁不要求建模、加權或假設；這些屬中學階段的另一個層次，不在本頁評分範圍之內，學生如提出，記下但不計分。
