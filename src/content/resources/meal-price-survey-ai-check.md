**本頁的價格，指學生按教師指定範圍自己記錄的一餐價錢；工具說的一個價錢，在核對之前只是一個說法。**

## 這個資源解決什麼問題

「這一區一餐大約多少錢？」學生把這條問題交給校方已指定的工具，工具回一個數，多數沒有寫日期，沒有寫地區的界線，沒有說是堂食還是外賣，也沒有說這個數是平均數、最低一筆，還是一個大概。數字看起來合理，於是寫進報告。

第二個缺口在條件。同一個「一餐」，早餐與午餐不是同一個價錢範圍，堂食與外賣不是同一個價錢範圍，連飲品與不連也不是。條件不同，兩個價錢就不可以直接比較；這一點不寫清楚，收集到的價錢再多也不能合併。

第三個缺口在份量基準。一盒、一碗、一份，是同一個價錢下的三種份量；份量基準不寫，兩個價錢看似相同，實際不是同一個東西。

第四個缺口在表述。工具說「平均」，我們手上只有幾筆記錄；工具說「最低」，那一筆可能只屬於某一天某一個地點；工具說「大約」，我們不知道那個「大約」是從哪一段範圍得來。平均數只是一個代表值，最高與最低各一筆只是兩個個別例子，兩者都不等於「每個人都是這個價錢」。

第五個缺口在判詞。被問「這個說法可不可以用的時候」，最常見的答案是「應該差不多」。沒有判詞，核對就沒有結果：表上的記錄排得整整齊齊，卻沒有人說得出工具的說話可否使用。

本頁只做五件事，數目固定：一、三項條件（餐類、堂食或外賣、連飲品或不連）；二、自己收集，四個格子（日期、地點、價格與單位、份量基準）；三、整理成表，找最高與最低各一筆，P5–P6 加計一個平均數；四、四項核對（日期、地區、餐類、表述）加來源一項；五、一句判詞三級。**本頁不做模型、不繪圖**，不教統計方法，不計算百分比或等級，不評分、不排名、不比較同學之間的花費，也不要求交出、上載或影印工具輸出、截圖或帳戶資料。

頁面一個真實價格都不出，所有示例都標明虛構。全頁不出現餐廳、外賣平台、連鎖店、應用程式、網站或型號；工具一律寫「校方已指定的工具」。

當工具自信地報出一個查不到來源的價錢，那就是一次人工智能幻覺；要消除它，只能靠事實查證，把價錢與自己記錄的表逐項核實。本頁也提醒學生不過分依賴工具：寫四個格子、合併成表、寫判詞，三件事都要自己動手。

**防線（寫入工作單，不得放寬）：** 調查範圍由教師指定，三種做法選一種——校內小賣部、教師提供的價目資料、教師帶領的指定路線；不由學生自行決定離開校園。不拍攝價錢牌或店舖，不記店名，不記任何人；全程只記日期、地點、價格與份量。地點一欄寫教師指定的範圍與代號，不寫店名。

## 學習目標

完成這一節後，學生能夠：

1. 寫出三項條件，並確認全班的三項條件相同。
2. 按教師指定的範圍收集記錄：P4–P5 每人兩筆、P5–P6 每人三筆；每一筆寫齊四個格子。
3. 把全班的記錄合併成一張表，找出最高與最低各一筆；P5–P6 加計一個平均數，並寫一句「平均數不能代表每一個人」。
4. 做四項核對（日期、地區、餐類、表述），並就來源一項只寫「有」或「沒有」。
5. 寫一句判詞：可以用、要加上條件才可以用、不可以用，另寫一句理由。

本頁對應**應用人工智能的反思**學習範疇，屬高小（P4–P6）的學習階段；初小（P1–P3）不設這一節的價格調查，同一格式若真的下移到初小，只做三項條件與兩筆記錄，不計平均數。價值觀上練三樣：**慎思明辨**是先問一句「這個價錢屬於哪一天、哪一個範圍」，才決定是否採用；**人機協作**是工具只負責被問一次，記錄、合併與判斷都由學生自己做；**適時適用**是知道哪一項核對值得停下來做，哪一項可以留待下一節。

本頁屬《中小學人工智能素養學習架構》的應用範圍；這一節的學與教重點是核對的次序，不是價錢的高低，所以教師示範與收束時給的回饋，只講記錄與核對，不講誰找到的價錢較便宜。

## 使用步驟

一節 60 分鐘。三項條件、四格記錄、四項核對、來源一項、判詞三級，數目固定，不加不減。

### 一、三項條件（固定三項，全班相同）

| 條件 | 選項 | 為甚麼要全班相同 |
|---|---|---|
| 餐類 | 早餐／午餐／晚餐 | 三餐的價錢範圍不同，混在一起就不可以比較 |
| 堂食或外賣 | 堂食／外賣 | 同一個餐，外賣與堂食的價錢可以不同 |
| 連飲品或不連 | 連飲品／不連飲品 | 飲品是另一個項目，寫法不同就不可比 |

三句要記住：三項由教師在開始前寫在黑板上，全班照同一個寫法；三項一改，之前收集的記錄要重做；三項不寫齊，該張表不可以合併。

### 二、自己收集（四個格子）

| 格子 | 寫甚麼 |
|---|---|
| 日期 | 收集當日，寫年月日 |
| 地點（教師指定範圍） | 教師指定的範圍與代號，例如校內小賣部、指定路線的第一點；不寫店名 |
| 價格與單位 | 價目上寫的價錢，照寫，單位寫「元」；不換算、不估算 |
| 份量基準 | 一盒／一碗／一份，照價目上的寫法 |

**階段分工（固定）：**

- **P4–P5**：每人兩筆，只找最高與最低，不計平均數。
- **P5–P6**：每人三筆，加計一個平均數。
- 同一班只用一種做法，由教師選定後全班一致；P5 兩邊都可以，選定一種就做到底。

四句要記住：每一筆的四個格子都要寫；三項條件在整節之內不變；只記這四項，不記店名、不記任何人、不拍攝；價錢照價目寫，不自行加減。

### 三、整理成表（全班合併）

全班把記錄貼到同一張表，或用黑板畫一張表逐筆填入。合併之前先看一次：三項條件是否全班相同；不相同的一筆要重做，不合併。

表填好之後做兩件事：

1. **找最高與最低各一筆**：寫出那一筆的日期、地點、價格與份量基準，不寫「某人」。
2. **P5–P6 加計一個平均數**：把同一條件的價錢相加，除以筆數，寫出單位（元）與筆數；然後寫一句**「平均數不能代表每一個人」**，並在旁邊寫出最高與最低各一筆，說明為甚麼。

三句要記住：平均數是一個代表值，不是每一個人的價錢；最高與最低各一筆只是兩個例子，不是排名；不合併不同條件的價錢，也不把兩班或兩日的價錢合成一個平均數。

### 四、四項核對與來源一項（固定四項＋一項）

用同一條問題問一次校方已指定的工具，例如「（三項條件照黑板）這一區一餐大約多少錢？」把工具的說法照原樣抄下，然後逐項核對：

| 核對 | 要問的問題 |
|---|---|
| 日期 | 工具的說法有沒有寫日期或期間？與我們收集的日子是否同一個期間？ |
| 地區 | 工具的說法有沒有寫地區的界線？與教師指定的範圍是否相同？ |
| 餐類 | 工具的說法有沒有寫餐類、堂食或外賣、連飲品或不連？ |
| 表述 | 工具的說法是「平均」、「最低」還是「大約」？我們手上的表支持哪一種？ |

問工具時只用這一條問題，不加提示詞去引導它給某一個數；工具給的數與我們的表不同，正是這一節要看的東西。

**來源一項**：只寫「有」或「沒有」——工具有沒有寫出資料從哪裏來。本頁不寫任何網站、應用程式或店名，所以來源一項不再往下查證，只記有沒有。

三句要記住：「表述」一項最常被放過：平均數不等於最低一筆，最低一筆也不等於「大約」；四項逐項寫「相同」或「不相同」，寫「不相同」的補一句差異在哪裏；來源寫「沒有」的，判詞不可以寫「可以用」。

### 五、一句判詞（固定三級）

| 判詞 | 甚麼情況寫這一級 |
|---|---|
| 可以用 | 四項核對全部「相同」，而來源一項為「有」 |
| 要加上條件才可以用 | 一至兩項「不相同」，寫明要加上哪一個條件（日期、地區、餐類或表述）；四項全同但來源為「沒有」，也寫這一級，寫明要補上來源 |
| 不可以用 | 三項或以上「不相同」，或表述一項與我們的表不符而工具仍寫「平均」或「最低」 |

三句要記住：判詞只寫一句，寫明哪一級與理由；三級之外不另設「大概可以」、「部分可用」；理由要寫到四項核對之中的一項，不寫「感覺上」。

### 六、60 分鐘分配、離線做法與收束

說明與示範 8 分 → 收集 12 分 → 合併成表與找最高最低 12 分 → 問工具與四項核對 14 分 → 判詞與全班讀出 8 分 → 收束與功課 6 分。

**離線做法**：教師預先印出價目資料（由教師預備，可以用虛構的示例價目）與一段工具的示範回答（同樣虛構），學生照樣做四個格子、四項核對與判詞。頁面與附件都不預載任何真實價格。

三句收束：

1. 三項條件寫得齊，價錢才比得上。
2. 平均數只是一個代表值，最高與最低各一筆只是兩個例子。
3. 判詞只有三級，寫明理由才算核對完成。

功課：換一個餐類（例如早餐），用同一張紙再做一次，只寫四個格子與一句判詞；不重做全班合併。

**與同類三頁的分工（逐頁）：**

- **與「我們丟掉甚麼：建立可核實的廢物圖表」**：那一頁由學生把官方數據畫成折線圖，重點在圖表與趨勢；本頁不繪圖、不做圖表，只做一次收集、一張表與一句判詞。
- **與「P4 香港人口折線圖：檢查 AI 生成的解釋」**：那一頁用官方人口數據檢查工具對一條折線的解釋；本頁的數據由學生自己按教師指定範圍收集，樣本很小，所以只找最高與最低，不解釋、不看趨勢。
- **與「城市怎樣移動：以官方數據核對 AI 的交通說法」**：那一頁抄的是政府部門公布的官方統計，四記法記的是來源、年份、表號與單位；本頁的數字是自己記錄的，沒有表號可寫，所以四個格子記的是日期、地點、價格與份量，並且不寫店名。

## 答案與評分要點

本頁不是評估工具：不給分數、不列等級、不作百分比排名、不入成績表，也不作操行或誠信紀錄；也不比較同學之間的花費。「完成」只看紀錄紙寫不寫得出來。

**完成時應該看到：**

- □ 三項條件寫在紙上，與黑板相同。
- □ 每一筆的四個格子都寫了：日期、地點、價格與單位、份量基準。
- □ P4–P5 兩筆；P5–P6 三筆，並有一個平均數與「平均數不能代表每一個人」一句。
- □ 最高與最低各一筆，寫的是日期、地點、價格，不是人名。
- □ 四項核對逐項寫了「相同」或「不相同」；來源一項只寫「有」或「沒有」。
- □ 判詞寫了一級與一句理由，理由寫到四項核對之中的一項。

**虛構示例（示範格式用，不是資料）**

| 項目 | 示例（虛構） |
|---|---|
| 日期 | 20XX 年 X 月 X 日 |
| 地點（教師指定範圍） | 指定路線第一點（代號 A） |
| 價格與單位 | XX 元 |
| 份量基準 | 一盒 |
| 工具的說法（虛構） | 「這一區一餐平均約 YY 元」，沒有寫日期、地區界線與餐類 |
| 日期 | 不相同（工具沒有寫期間） |
| 地區 | 不相同（工具沒有寫界線） |
| 餐類 | 不相同（工具沒有寫堂食或外賣） |
| 表述 | 不相同（工具寫「平均」，我們只有幾筆記錄，寫不出平均數的範圍） |
| 來源 | 沒有 |
| 判詞 | 不可以用：四項之中四項不相同，工具也沒有寫來源；要使用，先要補上日期、地區、餐類與表述四項。 |

> 上表的價錢、日期與代號全部是為本練習而設的**虛構示例**，不代表任何真實價錢、日期、地點或機構資料。

**另一個虛構示例，示範「要加上條件才可以用」：** 工具寫「20XX 年 X 月，指定範圍內，午餐堂食不連飲品，大約 XX 至 YY 元」，日期、地區、餐類三項相同，來源一項「有」；表述一項寫「大約」而我們的表最高與最低相差不大。判詞：「要加上條件才可以用：表述一項要寫明是這幾筆記錄的大約範圍，不是全區的平均。」

**常見答案與回應：**

- **只寫價錢，沒有寫份量基準。** 回應：份量基準不寫，兩個價錢不可比；回到價目把份量照寫。
- **把不同餐類的價錢合成一個平均數。** 回應：先按三項條件分開，再合併；不同條件不合併。
- **最高一筆寫了同學的名字。** 回應：只寫日期、地點、價格與份量，不記任何人。
- **工具沒有寫來源，學生仍寫「可以用」。** 回應：來源「沒有」不可以寫「可以用」；四項全同就寫「要加上條件才可以用」，寫明要補上來源。
- **判詞寫「大致可以」。** 回應：只有三級，選一級並寫理由。
