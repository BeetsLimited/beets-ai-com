> 貼進去之前先刪，比貼進去之後補救容易。一頁四問，逐項對照，四問全部答「沒有」，才可以輸入。

## 這個資源解決什麼問題

事故很少發生在工具身上，而是發生在貼進去的那一刻。教師要出一份練習、改寫一段說明、把一份紀錄整理成報告；整份文件被貼進去，裏面夾着學生的姓名、班別座號、家長的聯絡方法，或者一段可以認出是誰的紀錄。事後刪除工具裏的對話，並不會令已經離開學校系統的那一份資料回來。

官方文件對這一點的要求很直接：

> 「教師如需上載學生課業予人工智能平台批改，應先審慎移除可識別學生身份的部分，恪守《個人資料（私隱）條例》。」

同一份文件對學生一方的要求，用的是「匿名化」這個提法：

> 學生在輸入提示詞或上載資料時，只能提供「匿名化」的數據，絕不能輸入、上載或儲存真實姓名、學生編號等具個人識別的資訊。

兩句都指向同一個動作：**在輸入之前刪去**，而不是在輸入之後補救。這一頁就是把那個動作變成四條可以逐項回答的問題。

**本頁的範圍**：只講輸入前的那幾十秒。它不重複「可以輸入／不可以輸入」的清單（另一份資源已逐項列出），也不處理家長同意（那屬另一份資源的範圍），更不是一份新的校內政策。四問全部答「沒有」之後，是否需要其他程序，依學校既有規定處理。

## 學習目標

完成本檢查表後，使用者能夠：

1. 在貼上之前，用四條問題檢查一段準備輸入的內容。
2. 指出一段示例中可識別的部分，並寫出刪減後的版本。
3. 說明為甚麼「先刪後貼」比「貼後補救」可靠。
4. 在記錄欄記下一次檢查：由誰輸入、何時、資料類別，以及是否已匿名化。

## 使用步驟

檢查表是一頁 A4，可以獨立列印。四問的次序由最易判斷排到最難判斷：先找名字與編號，再找其他可以認出是誰的細節，然後才問「這一部分是否必須」。使用時由第一問開始；**任何一問答「有」，就回到該處刪去，然後由第一問重新開始**。四問全部答「沒有」，才可以輸入。

**第一問：有沒有一個名字或編號，可以直接認出是哪一位？**

姓名、學生編號、班別座號、家長姓名與聯絡方法、身分證明文件號碼。這一問最易判斷，也最常被略過：改了一個名字，卻保留了班別座號，仍然認得出是誰。

**第二問：有沒有其他細節，可以「對號入座」？**

相片、錄音、影片中的容貌與聲音、手寫字迹、校服與課室佈景、只有幾個人知道的特別事件。這一問比第一問難，因為它問的不是「有沒有寫出名字」，而是「看的、聽的人能否認出是誰」。

**第三問：這一部分，是不是完成任務所必須？**

可以刪去而結果一樣，就刪去。整份文件貼進去，通常有一半內容與任務無關；先問這一段為甚麼要在這裏，比事後在工具裏刪更可靠。

**第四問：刪去之後，工具仍然做得到我要它做的事嗎？**

這一問最難，因為它要求你想清楚任務本身。刪得太多，工具做不到；做不到的時候，正確的做法是**改問法**（例如只交出題目與寫作要求，不交出學生原文），而不是把資料加回去。

**刪減前後對照（以下三行均屬虛構示例，只用來說明格式）**

| 輸入前 | 刪減後 | 刪去了甚麼 |
|---|---|---|
| 「4A 班 陳〔姓名〕（學生編號 S〔號碼〕）的作文如下：……」 | 「一篇小四學生的作文（作者代號 S07），題目見下：……」 | 姓名、學生編號、班別座號；保留年級與代號 |
| 「〔一段課堂錄音〕請分析學生的說話表現」 | 「一段課堂對話的文字紀錄（學生代號 S07、S12），內容如下：……」 | 聲音、容貌；只保留任務需要的文字 |
| 「〔上學期全份紀錄〕請寫一段總結」 | 「以下三項紀錄（已刪去姓名及日期），請寫一段總結：……」 | 與任務無關的欄位、日期、地點 |

**記錄欄（每次檢查填一行）**

| 由誰輸入 | 何時 | 資料類別 | 已匿名化 |
|---|---|---|---|
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

記錄欄不是為了追究，而是為了兩件事：下一次遇到同類內容時知道要刪哪一處；學校在需要時說得出曾經做過甚麼。

## 答案與評分要點

**四問的判斷要點**

| 問題 | 答「有」時應怎樣做 | 最常見的誤答 |
|---|---|---|
| 第一問：名字或編號 | 以代號取代，對照表留在校內，不一併輸入 | 只改姓名，保留班別座號 |
| 第二問：其他細節 | 刪去相片、錄音、影片或可辨認的佈景；只保留文字內容 | 以為「沒有寫名字」就等於匿名化 |
| 第三問：是否必須 | 刪去與任務無關的部分 | 整份文件貼進去，之後才在工具內刪 |
| 第四問：刪後仍做得到 | 改問法，令任務在沒有該資料的情況下仍然成立 | 做不到就把資料加回去 |

**前後對照的達標樣子**

- 刪減後的那一段，仍然讀得通，仍然做得到原本的任務。
- 代號與真實身分的對照，只留在校內，沒有出現在輸入的內容裏。
- 刪去的每一項，都說得出為甚麼與任務無關。

**常見錯誤**

- **只換名字。** 班別座號、日期、地點組合起來，仍然認得出是哪一位。
- **把對照表一併貼上。** 代號就失去作用；對照表只可以留在校內。
- **貼完整份文件才在工具內刪。** 資料已經離開學校系統，刪除工具內的文字不能撤回。
- **刪得太多，令任務做不到。** 這是第四問要處理的情況：改問法，不是把資料加回去。
- **把「匿名化」寫成「刪去所有背景」。** 匿名化的意思是不可認出是誰，不是令內容失去意義。

**這一頁怎樣計達標**：四問都答得出來、對照示例刪得對、記錄欄有一行真實紀錄，即達標。檢查表是一項操作工具，不以分數評核。
