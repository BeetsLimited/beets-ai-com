> 家庭裡最常見的落差，不是「沒有講過」，而是講過之後**沒有寫下**：一頁紙、六條界線、五個欄、兩方簽名，之後隨時可以改。這一頁不頒布規則，只提供一張寫得下、改得動的表格。

## 這個資源解決什麼問題

學校把家長信發出去之後，家庭這一邊通常停在四種情況：

- **講過，但沒有寫下。** 一次對話裡講了六件事，一星期後只記得「唔好用咁多」。孩子記得的是語氣，不是界線；家長記得的是擔心，不是做法。
- **由一方頒布。** 家長寫好之後交給孩子簽名，孩子不知道為甚麼有這一條。由一方寫成的約定，通常守不過第一個月——不是孩子不合作，而是他沒有參與寫。
- **寫成禁令，沒有寫做法。** 「唔准用 AI 做功課」寫得很快，但功課要用；於是孩子只在看不見的時候用，界線反而消失了。
- **出事之後才第一次講。** 孩子遇到不對路的回應，第一個反應是關掉、刪掉、不說，因為怕被沒收、怕被罵。第六條界線之所以是「出事先講」，就是為了不讓這件事發生。

這四種情況都不是家長不關心。缺的是一頁寫得下、兩方都簽得名、可以隨時改的紙。本頁把五件事放在一起：**六條界線（每條一句）、三個情境（初小抄功課、初小生成家庭照、高小講心事）、一頁五欄約定（家長與學生兩方簽署，並寫明可隨時重新商議）、班主任 20 分鐘講解、家長一頁四要點。** 附件是兩份可編輯的 Word 文件。

**三點請先讀：**

1. **六條界線、三個情境、五欄格式與家長一頁，屬本資源的建議，不是教育局規定，也不是校規。** 學校只提供表格；約定的內容由每個家庭自己訂立。學校不宜代家庭填寫，也不宜把同一份內容派給所有家庭當作規定。
2. **這份約定不簽署、不交回，不影響任何校內安排。** 學校不收回條、不記錄誰交誰沒交、不作班際比較，也不把簽署與否寫進學生的任何紀錄。
3. **本資源不提供任何使用時數或時距建議。** 頁內不引述任何機構的時數數字（衞生署、世衞或其他），因為各機構的建議對象、情境與量度方式都不同，轉述容易變成一句沒有上下文的規定。要有固定時段，由家庭自行訂立並寫進第五欄。

**本頁與附件一律不寫的三件事：** 不列任何具名的工具、平台或應用程式名稱；不出現真實學校、人名或班別；不把約定寫成校規，也不用「不簽署會有後果」來促成簽署。三個情境全部標明虛構。

## 學習目標

完成這一份約定之後，家庭能夠：

1. 用六條界線講清楚「在我們家怎樣用」，每條一句，不必多寫。
2. 從三個常見情境辨認哪一條界線正在運作，以及可以怎樣回應。
3. 在五欄約定上寫出自己家的做法，由家長與學生兩方簽署，並寫明可隨時重新商議。
4. 用家長一頁的四要點與孩子談一次，而不是頒布一次。
5. 知道這份約定不是校規，也不以簽署與否作任何校內後果。

本頁環繞人工智能素養的三個學習範疇而寫，對應其中**應用人工智能的反思**一項；三個學習範疇是：人工智能的基本運作原理、人機溝通和協作、應用人工智能的反思。它落在**慎思明辨**與**價值觀與態度**之間：慎思明辨是分清「用得多」與「用得對」，價值觀與態度是把界線寫成人與人之間的約定，而不是單方面的禁令。

## 使用步驟

檔案是兩份 Word 文件：**家庭 AI 約定及三個情境**（含一頁五欄約定，可獨立影印）與**家長一頁**（單面）。約定隨家長信發出，班主任在班會或家長會用 20 分鐘講解一次；約定由家庭帶回家填寫，學校不收回。

### 第一步：六條界線，每條一句

六條的次序有意義：前三條講「用之前」，第四、五條講「用的時候」，第六條講「出事之後」。**六條不多不少**，不要加第七條（例如「每日 X 分鐘」或「不准問功課」），也不要把兩條合併。

| 界線 | 一句話 | 為甚麼是這一條 |
|---|---|---|
| 一　用前先講 | 開始之前，先同家裡一位成人講一句：用哪一個工具、做甚麼。 | 讓成人知道正在發生什麼事，不必在事後查。這是最省力的一條，也是最常被略過的一條。 |
| 二　不輸入他人資料 | 不把別人的姓名、相片、電話、地址、學校或班別輸入。 | 別人的資料不屬於我們，輸入一次就收不回來。相片尤其如此：上載別人的相片，等於代別人決定。 |
| 三　功課只作輔助 | AI 可以幫你想，不可以幫你交；交出去的部分，你要講得明自己怎樣做。 | 功課的用意是學會，不是交得出。講得明自己怎樣做，是這一條唯一的驗收方式。 |
| 四　不對路即停 | 一旦覺得不舒服、看不懂，或者對方叫你做平時不會做的事，立即停，並告訴一位成人。 | 判斷「不對路」不需要理由，也不需要先證明。停下來永遠是容許的。 |
| 五　固定時段 | 使用的時段由家庭訂立並寫在第五欄；**睡前一小時**與**飯桌**（家人一起吃飯的時間）不用。 | 睡前一小時與飯桌是家庭生活的固定位置，不放工具進去，界線就不必每晚重新談。 |
| 六　出事先講 | 出了事，先講；不會因為講了而被沒收、被罰、被罵。 | 這一條是整份約定的關鍵：如果「講了會被罰」，前五條都守不住。 |

三點使用上的提醒：

- **寫「做甚麼」，不寫「不准甚麼」。** 「用前先講」可以照做；「唔准亂用」無法照做。同樣一件事，寫成動作，孩子才知道下一步做什麼。
- **第五條的時段由家庭自訂，本資源不給數字。** 每個家庭的作息不同；把時段寫進第五欄，比抄一個時數有用。
- **第六條要說得出來。** 家長宜在簽署前講一次：「你講咗，我唔會即刻沒收。」這一句講不出口，第六條就只是紙上的一行。

### 第二步：三個情境，全部虛構

三個情境只用來說明界線怎樣運作。**以下情境均為虛構**：沒有真實學校、人名或班別，也沒有具名的工具或平台。班主任講解時只需選一個，不必三個都講（初小選情境一或二，高小選情境三）。

| 情境 | 發生了甚麼 | 哪一條界線在運作 | 可以怎樣回應（一句） |
|---|---|---|---|
| 一　初小抄功課 | 小二學生把工作紙的題目整段貼進一個對話式的 AI 工具，把答案抄回工作紙；家長在書桌上看到打印出來的一頁。 | 第三條（功課只作輔助）、第一條（用前先講） | 「呢題你自己講一次點做，我聽。AI 講嘅同你講嘅唔同，我哋一齊睇邊個對。」 |
| 二　初小生成家庭照 | 小四學生用一個生成工具做了一張「全家幅」，把家中長輩的相片上載，再把成品給家人看。 | 第二條（不輸入他人資料） | 「相片係別人嘅資料，唔可以上載。想要一張全家幅，我哋一齊影，或者一齊畫。」 |
| 三　高小講心事 | 小六學生近來每晚同一個對話式 AI 講學校發生的事，講到不願睡；家人問起，他說「冇嘢」。 | 第五條（固定時段）、第六條（出事先講） | 「你願意講，我好想聽。佢唔會累，亦唔會記得你。今晚講到呢度；聽日你想講，同我講。」 |

三點提醒：

- **回應只寫一句，不寫一段。** 一句話在現場說得出口；一段話在現場只會變成說教。
- **情境三最容易被處理成「不准用」。** 但孩子在那裡講的是學校的事；先接住「他願意講」這一件，再談時段。若涉及自傷、被欺凌、被引誘，或涉及金錢與相片，依學校現行機制即日交由輔導組或駐校社工處理；家長不要承諾「唔話畀人知」。
- **情境二的重點不是那一張圖。** 是「別人的相片不屬於我們」，以及有沒有替代做法。只說「唔准」，孩子下次只會偷偷做。

### 第三步：一頁五欄約定，兩方簽署

五欄由左至右填寫，第一欄已印好六條界線。**五欄不多不少**：不要加「後果」一欄（後果寫在第四欄之內，一句就夠），也不要加「分數」或「進度」一欄。

| 界線 | 在我們家是這樣做 | 由誰提醒 | 做不到時怎樣 | 幾時再談 |
|---|---|---|---|---|
| 一　用前先講 |  |  |  |  |
| 二　不輸入他人資料 |  |  |  |  |
| 三　功課只作輔助 |  |  |  |  |
| 四　不對路即停 |  |  |  |  |
| 五　固定時段 |  |  |  |  |
| 六　出事先講 |  |  |  |  |

五欄各有一個作用，缺一欄就寫不成一份可用的約定：

- **第二欄（在我們家是這樣做）** 是唯一真正要動筆的一欄。寫具體情況：哪一個時段、在哪裡用、誰在場。
- **第三欄（由誰提醒）** 寫一個人名或一個稱呼，不寫「大家」。界線沒有人記得，就不會發生。
- **第四欄（做不到時怎樣）** 寫一次對話，不寫一個懲罰。例如「當晚一齊睇一次，講返邊一條冇做」。
- **第五欄（幾時再談）** 寫一個時點，例如「學期初」或「下次家長日之後」；不必寫日期以外的細節。
- **簽署** 由家長與學生**兩方**各簽一次。只有一方簽名的不是約定，是一份通知。

約定頁底部印有兩行，必須保留：

> 本約定可隨時重新商議：任何一方提出，就在下一次對話中修改，修改後由兩方重新簽署。
>
> 家長簽署：＿＿＿＿＿＿＿＿　日期：＿＿＿＿＿＿　　學生簽署：＿＿＿＿＿＿＿＿　日期：＿＿＿＿＿＿

### 第四步：班主任 20 分鐘講解

講解的目標只有一個：讓家長知道這是一份**由家庭自己填**的表格，不是學校派下來的規定。四段，每段五分鐘：

1. **五分鐘：說明這不是校規。** 學校只提供表格；內容由家庭訂立，學校不收回、不記錄、不作比較。這一句要說得清楚，否則家長會以為不交回會有後果。
2. **五分鐘：六條界線逐條讀一次。** 每條只讀那一句，不逐條解釋，也不舉例超過一個。讀完請家長圈出最想先談的兩條。
3. **五分鐘：講一個情境。** 初小選情境一或二，高小選情境三。只講「發生了甚麼」與「可以怎樣回應一句」，不講「應該怎樣教孩子」。
4. **五分鐘：說明派發方式。** 隨家長信發出，單面影印；不設回條、不收回、不記錄。家長一頁與約定一頁一併給家長，讓家長知道兩頁的關係。

講解時不做的事：不評價任何家庭的教養方式；不比較班際簽署情況；不把簽署與否寫進學生的紀錄或成績表；不把六條界線講成「學校要求」。

### 第五步：家長一頁，四要點

家長一頁單面影印，隨家長信發出，也可以在家長會上派發。它只有四點，**不增不減**：

1. **一起寫，不由一方頒布。** 讓孩子先講一次他認為應該有哪幾條，家長寫下來。孩子講過的那一條，通常守得最久。
2. **寫「做甚麼」，愈具體愈好。** 寫時段、地點、由誰提醒；不寫「要自律」「要適可而止」這一類無法照做的話。
3. **做不到時先談，不即時沒收。** 沒收是最快的一步，也是最快令孩子下次不再講的一步。先問「今日邊一條冇做」，再談下一次怎樣做。
4. **每學期重新商議一次，孩子可隨時提出。** 孩子長大、功課改變、工具改變，界線也要改。改的時候由兩方重新簽署。

家長一頁底部同樣有一句：**這份約定不是校規；不簽署、不交回，不影響任何校內安排。**

## 答案與評分要點

本資源**不評分、不設等級**，也沒有標準答案：每個家庭的第二欄都應該不同。以下是班主任講解與家長回應時可用的要點。

**三個情境的可接受回應（各一句就夠）：**

- **情境一（初小抄功課）：** 先請孩子自己講一次怎樣做，再把 AI 的答案與孩子的做法並排看。可接受的回應有兩點：一是把「交出去的部分要講得明」講清楚；二是提供一個替代做法（先自己寫，再用它對答案）。**不可接受的做法**是把整份功課收走，或只說「唔准用」而沒有替代做法。
- **情境二（初小生成家庭照）：** 可接受的回應要講出兩件事——相片屬於別人，未經同意不可以上載；以及一個替代做法（一齊影、一齊畫、用一張已同意的相片）。只講「唔准」，孩子下次會偷偷做。
- **情境三（高小講心事）：** 可接受的回應要保留「他願意講」這一件，同時講明界線（它不會累、不會記得你、多數順着你講），並講明例外（若涉及自傷、被欺凌、被引誘、金錢或相片，會交學校處理，不會承諾保密）。

**一份可用的約定，有五個特徵（可用作檢核）：**

- 六條界線齊全，每條一句，沒有增加第七條。
- 第二欄六格都寫了具體情況，沒有一格寫「見上」或「同上」。
- 第三欄寫了人，不是「大家」。
- 第四欄寫的是一次對話，不是一個懲罰。
- 第五欄有兩方簽名，並保留了「可隨時重新商議」一行。

**檢核清單（班主任在派發前核對一次）：**

- □ 六條界線為用前先講、不輸入他人資料、功課只作輔助、不對路即停、固定時段（睡前一小時及飯桌不用）、出事先講，次序與字句一致。
- □ 五欄為界線、在我們家是這樣做、由誰提醒、做不到時怎樣、幾時再談，沒有增減。
- □ 約定頁只有家長與學生兩方簽署，並印有「可隨時重新商議」一行。
- □ 全份沒有出現任何具名工具、平台或應用程式。
- □ 三個情境均標明虛構，沒有真實學校、人名或班別。
- □ 全份沒有一句寫成校規，也沒有「不簽署會影響上課」一類說法。

## 官方文件參考

本資源庫所有資源均按《中小學人工智能素養學習架構》編寫，並屬《中小學數字教育發展藍圖》的政策範圍。

本資源對應：

- **《中小學數字教育發展藍圖》**（三摺頁，p.2）：要求學校在學校發展計劃中規劃數碼與 AI 教育，並向教師、學生與家長交代推行安排；把家庭的用法寫成一頁可填、可簽的表格，是「向家長交代推行安排」的一種做法。
- **附篇一：《中小學人工智能素養學習架構》**（p.1-4）：訂出三個學習範疇；本資源對應其中「應用人工智能的反思」，並以「人機溝通和協作」為背景。
- **《小學資訊與創新科技課程框架》（試行版）「人工智能初探」部分**：小學階段設有使用規則與「適合運用的情境」的課題；本頁的三個情境即按此編排。此框架屬**試行版**，中小學的用語一致，但中學階段沒有同等的官方課程框架，中學的依據是《中小學人工智能素養學習架構》與教育局通函。
- **教育局通函第 156/2026 號**（公布）：列出學校應用人工智能時須留意的價值觀與態度，包括合規守法與安全、慎思明辨，以及關注學生身心健康；本頁的「不對路即停」與「出事先講」兩條界線，即這一組要求在一張家庭表格上的做法。
